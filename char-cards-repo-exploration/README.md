# Character Cards Repository

A curated collection of character cards, persona cards, and lorebooks for use with [Serene Pub](https://github.com/doolijb/serene-pub) and compatible chat applications.

## Overview

This repository provides a centralized location for sharing and discovering character cards, personas, and lorebooks. Cards are organized by category and made searchable through automatically-generated YAML index files.

## Repository Structure

```
char-cards-repo/
├── README.md                  # This file
├── LICENSE                    # AGPL-3.0 with author exception
├── package.json              # Node.js dependencies
├── characters.yaml           # Auto-generated character index
├── personas.yaml             # Auto-generated persona index
├── lorebooks.yaml            # Auto-generated lorebook index (future)
├── src/
│   └── update.ts            # Script to regenerate YAML indexes
├── character-cards/         # Character card files
│   ├── *.json               # Uncategorized characters
│   ├── *.png
│   └── [category]/         # Optional category subdirectories
│       ├── *.json
│       └── *.png
├── persona-cards/           # Persona card files
│   ├── *.json               # Uncategorized personas
│   ├── *.png
│   └── [category]/         # Optional category subdirectories
│       ├── *.json
│       └── *.png
└── lorebook-cards/          # Lorebook files (future)
    ├── *.json
    └── [category]/
        └── *.json
```

## Categories

Character and persona cards can optionally be organized into subdirectories representing categories. Examples:

- `romance/` - Romantic characters
- `fantasy/` - Fantasy world characters
- `sci-fi/` - Science fiction characters
- `horror/` - Horror-themed characters
- `historical/` - Historical figures or settings

**Note:** Only one level of subdirectories is supported. Cards in the root directory are considered uncategorized.

## YAML Index Files

The `characters.yaml` and `personas.yaml` files are automatically generated by running the update script. These files provide searchable metadata for all cards in the repository.

### Character Index Format

Each character entry includes:

- **name** - Character name
- **nicknames** - Alternative names
- **description** - Excerpt from character description
- **personality** - Excerpt from personality traits
- **author** - Creator of the character
- **authorNotes** - Notes from the creator
- **tags** - Categorization tags
- **version** - Character card version
- **category** - Subdirectory category (if applicable)
- **path** - Relative path to the card file

### Persona Index Format

Each persona entry includes:

- **name** - Persona name
- **description** - Persona description excerpt
- **category** - Subdirectory category (if applicable)
- **path** - Relative path to the card file

Entries are sorted alphabetically by name and grouped by category (uncategorized first, then alphabetically by category).

## Usage

### Browsing Cards

1. Browse the YAML index files (`characters.yaml`, `personas.yaml`) to discover cards
2. Download individual card files from the corresponding directories
3. Import cards into Serene Pub or compatible applications

### Adding Cards

1. Place your card file (`.json` or `.png`) in the appropriate directory
2. Optionally organize into a category subdirectory (max 1 level deep)
3. Run the update script: `npm run update`
4. Submit a pull request with your additions

### Supported Formats

- **JSON** - CharacterCard V2/V3 spec JSON files
- **PNG** - PNG files with embedded character data

## Running the Update Script

To regenerate the YAML index files after adding new cards:

```bash
npm install
npm run update
```

This will scan all card directories and regenerate `characters.yaml` and `personas.yaml`.

## Character Card Specifications

This repository supports character cards conforming to:

- [CharacterCard V2 Specification](https://github.com/malfoyslastname/character-card-spec-v2)
- [CharacterCard V3 Specification](https://github.com/lenml/CharacterCard-V3-spec)

Cards are read using [@lenml/char-card-reader](https://www.npmjs.com/package/@lenml/char-card-reader).

## Contributing

Contributions are welcome! Please:

1. Ensure cards follow the V2 or V3 specification
2. Include meaningful metadata (name, description, tags, etc.)
3. Organize cards into appropriate categories when applicable
4. Test cards in Serene Pub or compatible software before submitting
5. Run the update script before committing
