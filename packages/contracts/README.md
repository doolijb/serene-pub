# `@serene-pub/contracts`

Generated, frozen type declarations for **one** Serene Pub release. The package version is
the SP release: `@serene-pub/contracts@0.6.x` is what compiles against SP 0.6.x.

Names are derived from type ids and never chosen — `core:provider/generate-text@1` is
`generateText`, `chariot.recall:rank-semantic@1` is `rankSemantic`. See `@serene-pub/cli`'s
`codegen.ts` for the rule and the check that keeps it true.

Do not edit. Regenerate with `serene-pub contracts --release <ver>`.
