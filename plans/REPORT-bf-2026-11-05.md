# REPORT bf — a lorebook file carries its rules (★M3b-S5-1, 2026-11-05)

## Field name (final, for the port lane)
`extensions.serenepub.primaryRuleset` (the ruleset id, e.g. `"mundi:ruleset/life"`) and optional `extensions.serenepub.rulesetVersion` (semver pin, e.g. `"0.2.0"`), beside `storyTime`. These are the same names as the `lorebooks.primary_ruleset` / `ruleset_version` columns (R1). Leave both out for a Freeform book. Only pin a version that the target pub keeps; an unkept version is dropped with a warning (see ★bf-2).

## Behaviour
- **Import** (create path and overwrite path): the check is `lorebooks:create`'s own `chosenBookRules` (`getRuleset`).
  - A ruleset this pub doesn't have puts the book on Freeform, with the warning _‹book› plays ‹id›, which this pub doesn't have — imported on Freeform._
  - A known ruleset with a version this pub never kept (`keptRulesetDocument`) is imported on that ruleset with no pin, with the warning _‹book› was made with version ‹v› of ‹id›, which this pub doesn't keep — it plays the installed version._
  - A file with no field: a new book takes the column default (Freeform), and an overwritten book keeps its rules.
- **Provided books:** `importFresh` → `importLorebookDocument` → `createLorebookFromParsedCard` inherits the read. An int test proves it through `syncProvidedBooks`. `providedBooks.ts` is not edited.
- **Export:** Freeform books write exactly the bytes they wrote before. `lorebooks.import-export.int.test.ts` is still green.

## Open ★ (built as recommended, owner to confirm)
- **★bf-1 Overwrite with a file that names no rules.** As built, the book keeps its rules. This is today's behaviour and the brief's "a file without the field imports as today".
  - Alternative: the book goes to Freeform, the way `overwrittenStoryTime` clears the clock ("the file replaces the book").
  - Trade-off: as built, overwriting a Mundi book with an export of a Freeform book (which carries no field) keeps Mundi. The alternative would reset books overwritten from older exports.
- **★bf-2 A version this pub never kept.** As built, the book stays on that ruleset with no pin (it follows the installed version) and a warning.
  - Alternative: the brief's literal "unknown → Freeform".
  - Trade-off: Freeform would lose the rules of any book exported from a pub on a different version.
- **★bf-3 Copy of the two warnings.** They name the ruleset by id, because an unknown ruleset has no name here.
