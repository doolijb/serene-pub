| A definition's `timeoutMs` / `timeoutKind`, the executor's `nodeClock` (`sdk/src/executor.ts` ~1898, ~2824) | **Off** |

## Where it lives and shows

Column `system_settings.step_time_limits_off` (default false); `stepTimeLimitsOff(db)` in `callTether.ts` is the
only reader; `runTurn` and `cardAction` read it at run start and pass `RunOptions.stepTimeLimitsOff: true`.
A standing notice to every administrator (cleared when switched off); an item on the Overview's **Needs you**
card; the card in Admin › Diagnostics after Context debugging; *Time limits off* on the Turn line, administrators
only, from a dossier field filled in the browser.

Stop: the executor checks `cancelSignal` only between nodes; Stop works with the switch on because core aborts
the run's own signal and every host request listens to it. A binding stuck in pure code waits until it returns.
