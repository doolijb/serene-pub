- **Query counts** (w2 measured them with a temporary counting test, since deleted). Fixture: N = 6 sessions, K = 3 candidates (an attached-book own name, an own-book face, and two seats where one member is found by card).

  | Call | Before | After |
  |---|---|---|
  | `lastVisibleMessages` for the list | 37 | 24 |
  | `seatCastShownForSessions` for the list | 37 | 26 |
  | **The list pair** | **74** | **50**, prefilter run once |
  | Push, one non-candidate session | 3 | 3 |
  | Push, one candidate session | 15 | 13 |

  - **Before**, each function cost 1 prefilter + its base reads + K × (book 2–3, homes 1, find up to 2 per card per book, about 7 per `membersAsRead` round).
