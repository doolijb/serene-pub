## Background
Serene Pub makes two connections itself — **Local embeddings** (`local-onnx`) and **Local named entities** (`local-onnx-ner`) — wherever the ONNX runtime loads. Their names are fixed and they can't be deleted there (the server refuses: `sockets/connections.ts`, on the generic `"error"` event). The Connections sidebar already hides Delete and makes the name read-only for them (`src/lib/client/components/sidebars/ConnectionsSidebar.svelte` ~237-249, an inline `$derived` named `comesWithApp`: `isLocalOnnxType(type) && connectionTypeDisabledReason(type, localOnnxAvailability) === null`). Where the runtime can't load, a leftover row stays editable and deletable (ruled). Admin › Connections still offers Delete, rename and bulk delete on them; the quant picker's Escape closes the whole Set up chat dialog.
