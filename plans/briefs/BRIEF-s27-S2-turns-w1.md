## Background (what S2 is — read, don't re-derive)
Sessions seat **cast members** (rows of `lorebook_bindings`); each seat (`session_characters` / `session_personas`) now stores `cast_member_id` beside the card it holds (`character_id` / `persona_id`). Stage S2 switches **readers** onto the seated member. It changes **no stored key and no stored data**: `character:<cardId>` refs, the turn order in the core annex, `turnTally`, `rewind_taken`, `session_cast:<cardId>` owners all stay card-keyed (S4 rekeys). Refs core **emits** stay `character:<cardId>` / `player-seat:<id>`. Refs **coming in** (from a client payload, a plugin's output, a script) must also accept the 🚧 form `seated-member:<memberId>` and are translated **at the door** to the card form the keys use.

Helpers already built — use these, never write a second copy:
- `src/lib/server/sessions/seats.ts`: `parseSeatRef(ref)` → `{form:"character"|"seated-member"|"player-seat", id}|null` (pure); `seatOf(db, sessionId, ref)` → `ResolvedSeat {kind:"character"|"player", seatId, castMemberId, cardId, departed} | null` (live before departed, character seat before player seat, then lowest position, then lowest id; never an envoy).
- `src/lib/server/pipelines/prompt/seatCards.ts`: ⏳ `cardFormRef(db, sessionId, ref)` — a `seated-member:<id>` ref → `character:<cardId>` (or a card-less player seat's `player-seat:<id>`); **any other ref comes back unchanged with no query**; null when the session seats nobody as that member. ⏳ `cardFormRefInCast(cast, ref)` — the same over a `session_cast` read in hand (no db). `seatCardsAsRead(db, sessionId, rows)` — card-shaped seat rows (`{castMemberId?, character}`) with each card filled from the seat's member (name, nickname, retold text), over the card the seat holds. `cardsAsSeatsRead(db, sessionId, cards)` — the same for a reader holding card rows (`{id, name, nickname, …}`), each read through the session seat holding it.
- `src/lib/server/cast/memberAsRead.ts`: `memberAsRead(db, memberId, { sessionId, overCards: new Map([[memberId, seatCardId]]) })` → `MemberAsRead` (`activeCardId`, `name`, `nickname`, `shownName`, `faceMediaId`, …). With `overCards` the active card IS the seat's card.
- `$lib/shared/lorebooks/memberIdentity.ts` `memberShownName(member, card, fallback)` = nickname || name || fallback after the member's own names. Passing `undefined` as the member and an already-filled card row gives the filled row's shown name.
- The SDK's `parseParticipantRef` **throws** on `seated-member:` (it is not an SDK form until S3). So every door that parses a raw ref with the SDK must run `cardFormRef` (or `cardFormRefInCast`) first. Do **not** edit the SDK.
