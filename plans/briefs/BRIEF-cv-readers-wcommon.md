## The design you work inside (character versions, S4 stage 1 — built)
- One table `character_versions`: a version belongs to a **card** (an authored release, `number` + `label`) or a **cast member** (`lorebook_bindings` row; its evolution on a book line). Every version holds a complete 🚧 **character profile** (`CharacterProfileV1`: name, nickname, aliases, summary, description, personality, scenario, greetings `{text, groupOnly?}[]`, example dialogues, post-history instructions, creator notes `{text, lang?, variants}`, strokes, face, likeness, timbre, sprite set, extensions) with `follows[]` naming the fields read from the parent card version.
- **The one member reader:** `cast/memberAsRead.ts` — `membersAsRead(db, memberIds, { sessionId } | { reading })` / `memberAsRead(...)` → `MemberAsRead` (every profile field as read, `shownName`, `activeCardId` = the parent card version's card, `cardless`, `faceMediaId`, `likeness`, `timbre`, `spriteSets`, …). `castVersionsInForce(db, memberIds, opts)` → the version row in force per member.
- **Seat readers** (`pipelines/prompt/seatCards.ts`): `seatMembersAsRead(db, sessionId, rows)` (the member each seat row seats), `seatCardsAsRead(db, sessionId, rows)` and `cardsAsSeatsRead(db, sessionId, cards)` (a card row read as the member of the seat holding it), and `seatCardAsRead(card, asRead)`, which now lays **every** profile field of the member over the card row in the card's column names (name, nickname always; each other content column the row carries — description, greetings, post-history, notes, strokes, `avatarMediaId` = face, likeness/timbre under `extensions`, aliases, summary).
- **New today (supervisor-written, use them, don't change them):**
  - `cardsNow(db, cardIds): Promise<Map<cardId, CardNow>>` in `cast/seatedCast.ts` — cards as their **current card version** has them (highest `number`), in the `characters` row shape (library facts from the row, content columns from the version via `cardAsOfVersion`). Never reads the ⏳ copy columns. A card with no version gets v1 lazily (`ensureCardVersion`).
  - `cardsNowAsSeatsRead(db, sessionId | null, cardIds): Promise<Map<cardId, CardNow>>` in `pipelines/prompt/seatCards.ts` — `cardsNow`, then (with a session) read through the member of the seat holding each card. **The one-liner for "name/draw this card id as this session reads it".**
