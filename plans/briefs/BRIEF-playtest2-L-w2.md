## The one helper — new `src/lib/shared/lorebooks/memberIdentity.ts` (pure, shared; every reader goes through it)
```ts
export interface MemberOwnNames { ownName?: string | null; ownNickname?: string | null }
export interface CardNames { name?: string | null; nickname?: string | null }
/** A save's value: trimmed text, or null for blank / not a string. */
export function ownNameValue(value: unknown): string | null
export function hasOwnNames(member: MemberOwnNames | null | undefined): boolean
/** The name and nickname a carded member is shown by in this book. */
export function memberNames(member, card): { name: string; nickname: string | null }
/** nickname || name || fallback — the resolveCharacterName rule, applied after the member's own. */
export function memberShownName(member, card, fallback = ""): string
/** The card as this member is shown: name/nickname replaced; the SAME object when the member has no own names. */
export function withMemberNames<T extends CardNames>(card: T, member): T
/** The face the member is drawn with: their face while `retold.face === true` and a `faceMediaId`, else the card's `avatarMediaId`, else null. */
export function memberFaceMediaId(member: { faceMediaId?: number | null; retold?: { face?: boolean } | null } | null | undefined, card: { avatarMediaId?: number | null } | null | undefined): number | null
```
**The rule (supervisor's decision, say it in the module doc):** `name = ownName ?? card.name ?? ""`; `nickname = ownNickname ?? (ownName != null ? null : card.nickname || null)` — a book name of its own drops the card's nickname unless the book also gives one, because a nickname is a short form of a name and the card's would otherwise keep showing over the new name (resolveCharacterName prefers the nickname). Treat `""` like null on both sides. A member with neither own field reads exactly as the card does (test byte-for-byte equality with `resolveCharacterName(card, fallback)`). The module doc says: the override is "Shown in this book only; the card keeps its own"; ⚠ not a retold field (no flag), not an amendment, not a config *override* (§6); "portrait" in the ruling is the member's **face** (§8) by R1.
