## Build — `src/lib/server/state/handEdits.ts` (new)
- `handEditRefusal(db, { sessionId, userId, owner, slotId, act, lock? }) → Promise<HandEditRefusal | null>` where `type HandEditRefusal = { cause: HandEditCause; sentence: string }` (`lock?: boolean` only for `configure`: whether the config carries a `lock` key — picks the sentence, below). Null = allowed.
- `handEditJudge(db, sessionId, userId)` → a context loaded once (role, the four resolved levels, which are pinned, the ruleset, `sessionLinks`, hearing, seat and card ownership) with a **synchronous** `refusal({ owner, slotId, act, config })` and `whose(owner)` and `role`, for `describeState` (which judges every slot of every owner — no per-slot DB reads). `handEditRefusal` builds on it (plus an async read for a `card` / `cast_member` owner's character and owner, and the slot's config via `configFor` for its lock).
- Every read goes through the `db` handle passed in (it is `tx` inside `decideOffer`'s transaction — **never the module `db`**): `checkSessionAccess(sessionId, userId, handle)` (`utils/sessionAccess.ts` takes a handle), `session_guests.is_player`, `resolveSessionSettings(db, …)` (`sessions/settings.ts`; its `fields` already include genre pins) and `getSessionGenre` (`pipelines/entities/sessionGenres.ts`) for which keys the genre declares in `shape.fields` (absent there = **pinned**), `sessionLinks` / `hearingOf` / `earshotSlots` / `valueHeard` (as `sockets/state.ts`'s `unheardWrite` uses them), `getRuleset(session.primaryRuleset)` + `attributeSlotsOf` / `sectionsOf` (`rulesets/functionRun.ts`) for the attribute's `changedBy`.
- **Role:** session owner (`isOwner`) → `owner`; a guest with `is_player` true → `player`; a guest with `is_player` false, or anyone else → `watcher`.
- **Whose** (seen from the role): `session`, `lorebook`, `location`, `session_location` → the owner's (own for `owner`, other for `player`). `player_seat` → own iff `session_personas.user_id === userId`. A character (`session_cast` id, `card` id, `cast_member` → its binding's `characterId`): for a **player**, own iff `characters.user_id === userId`; for the **owner**, other iff the character is the persona of a live (`removed_at` null) player seat whose player (`user_id ?? characters.user_id`) is somebody else; otherwise own (their own cards and the NPCs).
- **Levels:** owner → `ownerSheetLatitude` / `ownerItemMoves`; player → `playerSheetLatitude` / `playerItemMoves`.
- **Sentence per cause** — default `HAND_EDIT_SENTENCES[cause]({ attribute })` where `attribute` = the slot's label as `changedByRefusal` builds it today (`i18nTextIn(decl.label) ?? slotKey(slotId)`), with these app overrides (today's sentences kept):
  - `unheard` → exactly today's `unheardWrite` sentences (move that name-filling code here): *"Only the session's owner and whoever plays {name} can change {name}'s {label}."* / *"Only the session's owner can change {whose}."*
  - `locked` → `LOCKED_REFUSAL` (*"This stat is locked."*, `state/write.ts`).
  - `changed-by` → today's two: owner role *"{label} changes only by the rules — a function or a reply that carries changes — never by hand."*; player *"Only the game master or the rules change {label}."*
  - `not-theirs` → on a seat or a played character: today's *"only {name}'s player or the session's owner can change their sheet."* (use the same name/"its" logic as `assertSessionOwner` had); on the world, a place or an NPC (player role): 🚧 *"The world, its places and the people nobody plays are the session owner's to change."*
  - `no-edits` → player, level exposed: *"Players don't edit sheets by hand in this session. The session owner can change that in the session's settings, under Players."*; player, level pinned: 🚧 *"Players don't edit sheets by hand in this genre."*; owner: the SDK default.
  - `no-moves` → player, exposed: 🚧 *"Players don't move items by hand in this session. The session owner can change that in the session's settings, under Players."*; pinned: 🚧 *"Players don't move items by hand in this genre."*; owner: the SDK default.
  - `watching` → the SDK default (*"You're watching this session; only its players and owner change sheets."*).
  - `owner-locks` → with `lock: true` (or for any configure that sets/clears a lock): the SDK default (*"Only the session owner locks or unlocks a stat."*); a configure without a lock key: 🚧 *"Only the session owner changes how a stat is set up."*
- Header doc in the P6 charter shape (purpose, why, owns, does NOT own — the judge is the SDK's; the levels' storage is the settings cascade's; runs never reach it).
