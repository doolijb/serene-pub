## What `castMember.ts` does

1. **Resolve `member`** → a cast member id, for session S (one function, used by both the read and the write):
   - a string `seated-member:<n>` or `player-seat:<n>` (trimmed) → `seatOf(db, S, ref)`; no seat → refused (the member/seat isn't seated in this session); a seat with `castMemberId == null` → refused (that seat voices no cast member).
   - a positive safe integer → that `lorebook_bindings` row; refused when it doesn't exist, when it is an overlay row (`overlay_of` set — name the member it overlays), or when its `lorebook_id` is neither the session's lorebook (`sessions.lorebook_id`) nor in `overlayChainOf(db, S)` (the session's own notes and its ancestors').
   - anything else (incl. `character:<id>`, a numeric string, null) → refused, naming the three accepted forms.
   Refusals are thrown as a small exported error class of this module (e.g. `CastMemberRefusal extends Error`) carrying the sentence; host.ts maps it to `HostScopeError`.
2. **Read** → `CastMemberV1`: `membersAsRead(db, [id], { sessionId: S })`, then `{ castMemberId, cardId: read.activeCardId, cardVersion: read.cardVersion, cardless: read.cardless, behindCard: read.behindCard, follows: read.follows, profile: profileOf(read) }`. A member the read doesn't return → refused. Type the result with `import type { CastMemberV1 } from "@serene-pub/sdk"`.
3. **Write**:
   - Gate first: `loreWriteRefusal(db, S)` non-null → refused with that sentence (`writes.lore`). The lore write mode needs no code here: `writeCastVersion`'s story path routes itself (book line, or the session's overlay row under Review / Off).
   - Check `changes`: a plain object with at least one defined key; every key a character profile field (`isCharacterProfileField`) — anything else (incl. `nodeState`, `nodeVisibility`, `first_mes`) refused, naming the key; each value either exactly `{ follow: true }` or a value that survives the profile's own normalisation unchanged (compare `profileOf({ [key]: value })[key]` with `value` by stable JSON — `profile.ts` has a private `stableJson`; write a local one), else refused naming the field and its expected shape; `name` must be a non-empty string.
   - ★cv-sdk-1 (provisional, the supervisor asks the owner; build it as written): compared with the member as the session reads it now (`membersAsRead`, outside any transaction), a change that would set a different `faceMediaId`, `likeness.imageMediaId`, `timbre.voice` or `timbre.narrationVoice` is refused (a face or likeness image is a file a person chooses; a voice is the admin's to pick). Unchanged values and `{ follow: true }` pass.
   - Then `db.transaction(async (tx) => writeCastVersion(tx, { member: id, changes, writtenBy: \`run:${runId}\` (no run id → \`session:${S}\`, as ties.ts), session: { id: S, messageId } }))` — `tx` only inside. `messageId` comes from host.ts: the turn (`turnMessageId ?? turnMessageOf(scope.runId)`, as `imprintAnchor` computes it; undefined when none — `writeCastVersion` then anchors to the world's turn or refuses in its own words). Let the writer's own errors propagate unchanged.
   - Return `{ id: version.id, castVersionId: version.id, castMemberId: id, coalesced }`.
4. host.ts commit case: `sessionId` required (copy update-lore-entry's `HostScopeError` sentence form); call the write; map `CastMemberRefusal` → `HostScopeError`; if host.ts keeps a per-run cast/lore read cache that this write invalidates (look for what update-lore-entry clears — `lorebookReads.clear()`), clear it the same way. Do NOT add a run artifact kind (`receipts.ts` `RunArtifact.kind` has none for cast versions — note it instead).
5. host.ts read case: `assertScoped(node, q.sessionId, scope.sessionId)` like its neighbours; no session → `HostScopeError`; else the read; map `CastMemberRefusal` → `HostScopeError`.
