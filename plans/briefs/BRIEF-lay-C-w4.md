### 2. `ZoneColumn.svelte` (new — ONE height engine for all three zones, D10)
Props `{ zone: "left" | "middle" | "right"; panels: DrawnPanel[]; gapPx: number; isMessages: (id: string) => boolean; panel: Snippet<[DrawnPanel, { index: number; count: number; widthPx: number; heightPx: number }]> }`. Measuring a Fit panel's content: per fit cell, a ResizeObserver on the active pane's widget root — `cell.querySelector('.wtab-pane:not(.wtab-hidden) [data-sp-widget-box] > *')` (remote DOM lands in the page) — want = `max(root.scrollHeight, root.getBoundingClientRect().height)` + the panel's tab strip height (`.ptabs-head`, if any) + the panel's vertical border; re-query the root when the cell's subtree changes (a `MutationObserver` childList+subtree on the cell, disconnected on destroy) and when `p.open` changes.
