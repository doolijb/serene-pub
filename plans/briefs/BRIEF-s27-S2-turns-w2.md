## Background (what S2 is — read, don't re-derive)
Sessions seat **cast members** (rows of `lorebook_bindings`); each seat (`session_characters` / `session_personas`) now stores `cast_member_id` beside the card it holds (`character_id` / `persona_id`). Stage S2 switches **readers** onto the seated member. It changes **no stored key and no stored data** except one thing this brief asks for (the speaker stamp, a column S1 added for exactly this). `character:<cardId>` refs, `session_cast:<cardId>` owners, message `character_id` / `persona_id` all stay card-keyed (S4 rekeys). Refs core **emits** stay `character:<cardId>` / `player-seat:<id>`; refs **coming in** also accept 🚧 `seated-member:<memberId>`.

Helpers already built — use these, never write a second copy:
- `src/lib/server/sessions/seats.ts`: `parseSeatRef(ref)` (pure) and `seatOf(db, sessionId, ref)` → `ResolvedSeat {kind:"character"|"player", seatId, castMemberId, cardId, departed} | null` — accepts `character:<cardId>` (the character seat holding the card, else the player seat holding it), `seated-member:<memberId>`, `player-seat:<seatId>`; live before departed, character seat before player seat, then lowest position, then lowest id; never an envoy. **No static `$lib/server/db` import** in it.
- `src/lib/server/pipelines/prompt/seatCards.ts`: `cardsAsSeatsRead(db, sessionId, cards)` — card rows (`{id, name, nickname, …}`) each read through the session seat holding it (member's own name/nickname and retold text, over the card the seat holds); a card no seat holds, or whose seat has no member, comes back as it was; same order. `seatCardsAsRead(db, sessionId, rows)` — the same for seat rows `{castMemberId?, character}`. ⏳ `cardFormRef(db, sessionId, ref)` — a `seated-member:` ref → `character:<cardId>` / `player-seat:<id>`; any other ref unchanged with no query; null when nobody is seated as that member.
- `src/lib/server/cast/memberAsRead.ts`: `membersAsRead(db, ids, { sessionId, overCards })` / `memberAsRead(db, id, { sessionId, overCards: new Map([[memberId, seatCardId]]) })` → `MemberAsRead` (`activeCardId`, `name`, `nickname`, `shownName`, `faceMediaId` — the member's face while retold, else the card's avatar, …). With `overCards` the active card IS the seat's card.
- `$lib/shared/lorebooks/memberIdentity.ts` `memberShownName(member, card, fallback)` = nickname || name || fallback after the member's own names; `memberShownName(undefined, filledCard, fb)` reads a row already filled by `cardsAsSeatsRead`.
- The SDK's `parseParticipantRef` **throws** on `seated-member:`: run `cardFormRef` first wherever a raw ref is parsed with the SDK. Do **not** edit the SDK.
- **Player seats** keep today's names (seat name, else the card's) in every roster: whether they read their member is an open question for the lead (★1 of lane promptText). Character seats read the member.
