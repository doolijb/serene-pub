### B. `sessions/seats.ts`
1. `seatCast` input gains `seatedBy?: number | null` — "the person seating it (owner §33.4: acting rights follow the seater)". On INSERT write `seatedByUserId: input.seatedBy ?? <the card's owner, characters.user_id>` for a card seat (an envoy seat: `input.seatedBy ?? null`). On the revive upsert (`onConflictDoUpdate`): when `input.seatedBy !== undefined` set it; otherwise keep the row's value, filling a null one: `sql\`coalesce(${t.seatedByUserId}, excluded.seated_by_user_id)\``. `onExisting: "keep"` writes nothing (as now). Doc comment: callers that don't pass it yet get today's rule (the held card's owner).
2. `SeatBook` gains `ancestorBooks: { lorebookId: number; mark: number }[]` — the own books (`lorebooks.session_id`) of the session's `branch_ancestry`, nearest first, each with that ancestor's mark; `seatBookOf` reads them (two small queries; empty for a non-branch).
3. `findSeatMembers` widens: after the attached book and the own book, each `ancestorBooks` entry in order. A member found there counts only when it **passes the cut**: the lowest `write_order` of its `character_versions` rows (`cast_member_id` = it) is ≤ that ancestor's `mark`; a member with no version at all counts (it predates versions). Its result keeps `lorebookId` = the ancestor's book. (`resolveSeatMember`'s order is unchanged: attached found → mint into attached → own → ancestors.)
4. `settleSeats(tx, sessionId, opts)` opts gains `seatMembers?: ReadonlyMap<number, number>` (card id → member id): seeds the per-call `known` cache, so those cards take exactly those members, live and departed seats alike. Fill-only rule unchanged.
5. `ResolvedSeat` gains 🚧 `actingUserId: number | null` — a character seat's `seated_by_user_id`, a player seat's `user_id`; `seatOf` selects them. Update every existing test that deep-equals a `ResolvedSeat` (`seatOf.int.test.ts`, `seatOf.test.ts`, others you find with grep).
6. New export 🚧 `seatActorOf(tx: Db, sessionId: number, seat: ResolvedSeat): Promise<number | null>` — who acts for the seat: `seat.actingUserId`, else (unset: a seater whose account went, a player seat from before `user_id`) the owner of its cast member's **active card** on the session's reading (`memberAsRead(tx, seat.castMemberId, { sessionId })?.activeCardId`, dynamic import of `$lib/server/cast/memberAsRead`), else the owner of the seat's own card; null when none.
