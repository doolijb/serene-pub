## Decisions
- Edit the card is also hidden in a read-only book (it only appears via `!readOnly`), so the two buttons are exclusive; "admin" access counts as "not the reader's book" and gets the guest line when the admin owns the card.
- Viewer id comes from `userCtx.user.id`; ownership is `selectedRow.character.userId === viewer id` on the resolved row (after a dated card swap the row's `character` comes from the reader's own card list, so it stays correct).
- Index-keyed `{#each}` for the sentence, written without inter-tag whitespace so `textContent` is character-for-character the old words.
