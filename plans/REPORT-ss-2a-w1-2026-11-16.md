## The fold as built
`foldSessionOverrides(db): SessionOverrideFoldReport` `{moved, shadowed, connections, leftNoSession, leftNoRegistration, leftUnmappable}`. One select; zero report when no session-scope rows. One tx per session (only `tx`, passed as `Db`), `invalidateRegistrations()` after a session that wrote.
Per row: connection slot -> delete (needs the spec's active version for decls; checked before the session/registration tests). Session gone -> leftNoSession. No active version or `sessionRegistrationKeys` empty -> leftNoRegistration. Per key: `registrationValueLayers(registrationKey)` -> `addressedValues` + `shippedConfigValues`, reading only addresses the layer states (as world.ts `resolvedLayer` does); usable = what `pushValues` pushes (null/undefined no; prompt: number/digit string and non-empty `resolvePromptFields`; template: inline `{source:string}` or number naming a row; variable: number naming a row of that address's variable). No key needs it -> delete (shadowed). Unmappable (null, address not in decls/variableKeys, or `addressedValues(valuesWith(null,addr,v))` not exactly one equal entry at the same key) -> leave. Else `patchSessionRow(…,"upgrade")` on each needing key, delete row. Logs: one `console.log` (moved/deleted), one `console.warn` (left).
