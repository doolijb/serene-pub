# Serene Pub 0.6.0-pr-2 release notes

A fix-up preview for 0.6, released in October 2026. Everything in [0.6.0-pr-1](./0.6.0-pr-1.md) still applies; read those notes first if you're coming from 0.5.3.

> **This is a preview build.** Your data comes across by itself, and a backup is taken before anything changes.

## Fixed

- **Android: the update from 0.5.3 now installs.** 0.6.0-pr-1's Android build carried an older internal version number than 0.5.3, so phones refused it as a downgrade ("App not installed"). This build installs over 0.5.3 and keeps your data. If you tried pr-1 on Android and it wouldn't install, use this one instead; you don't need to uninstall anything.

## For plugin authors

The SDK packages are now `0.6.0-pr-2` on npm (under the `next` tag). Nothing in their API changed since pr-1; this release tidies how they're built and published, and each SDK version now gets its own GitHub release with the exact package files attached.

## Downloads

The same downloads as 0.6.0-pr-1: Windows, macOS (Apple Silicon and Intel), Linux, Android, and the Docker image. See [Install Serene Pub](../install.md).

## Reporting a problem

Open an issue on [GitHub](https://github.com/doolijb/serene-pub/issues) with what you did, what you expected, and what happened. **Settings › About** can copy a support report to paste in.
