# Serene Pub 0.6.0-pr-3 release notes

A fix-up preview for 0.6, released in October 2026. It replaces 0.6.0-pr-2, which was never published. Everything in [0.6.0-pr-1](./0.6.0-pr-1.md) still applies; read those notes first if you're coming from 0.5.3.

> **This is a preview build.** Your data comes across by itself, and a backup is taken before anything changes.

## Fixed

- **Android: the update from 0.5.3 now installs.** 0.6.0-pr-1's Android build carried an older internal version number than 0.5.3, so phones refused it as a downgrade ("App not installed"). This build installs over 0.5.3 and keeps your data. If you tried pr-1 on Android and it wouldn't install, use this one instead; you don't need to uninstall anything.
- **Android: the app now starts.** It runs on Node.js 24, the version Serene Pub 0.6 needs; pr-1's Android build still carried Node.js 18 and crashed while starting. Dates and numbers now format with the engine's own built-in support, and the app is ready for phones that use 16 KB memory pages (Android 15 and newer). See [Android app](../android.md#nodejs-runtime).
- **Android: the new icon.** The app's launcher icon was still the old fox; it now matches the desktop and web icon, and fits whatever icon shape your phone uses.
- **Linux: the window is no longer empty.** On some systems, Zorin OS among them, Serene Pub's window stayed blank: a font package that ships web-format fonts (OpenDyslexic) stalled the system's WebKit before it drew anything. The window now leaves those fonts out, and opens in under a second.
- **Linux and Windows: the window shows the Serene Pub icon.** The window had a generic icon in the dock and taskbar. On Linux it now also groups under the applications-menu entry from `install-desktop-shortcut.sh`; run that script again to pick this up.
- **Windows: the download is back.** pr-1's Windows build stopped at the licence check over one compression library (pako, MIT and zlib licensed); zlib is now on the accepted list.
- **Smaller downloads.** The desktop builds no longer carry the SDK's documentation compiler, other platforms' copies of the local-embeddings engine, or command shortcuts nothing runs.

## For plugin authors

The SDK packages stay at `0.6.0-pr-2` on npm (under the `next` tag). Nothing in their API changed since pr-1; this release tidies how they're built and published, and each SDK version now gets its own GitHub release with the exact package files attached.

## Downloads

The same downloads as 0.6.0-pr-1: Windows, macOS (Apple Silicon and Intel), Linux, Android, and the Docker image. See [Install Serene Pub](../install.md).

## Reporting a problem

Open an issue on [GitHub](https://github.com/doolijb/serene-pub/issues) with what you did, what you expected, and what happened. **Settings › About** can copy a support report to paste in.
