Welcome to Serene Pub for Linux!

Thank you for downloading Serene Pub.

What's in this folder
---------------------

   serene-pub/
     serene-pub                   <- double-click to start
     install-desktop-shortcut.sh  <- optional: adds Serene Pub to your app menu
     .env.example                 <- settings reference
     app/                         <- the application itself
       run.sh                     <- starts only the server, no launcher

Everything that IS the application lives in "app/". An update replaces that one
folder in a single move, which is why nothing you own is kept inside it - your
database and settings live in your data directory instead (see Configuration
below).

To run the app
--------------

1. Extract the archive somewhere permanent, such as your home folder.

2. Double-click "serene-pub". If your file manager opens it as a file instead,
   right-click it and choose "Run as a Program", or run it from a terminal:

         cd /path/to/serene-pub
         ./serene-pub

3. A Serene Pub icon appears in your panel's tray, and Serene Pub opens in its
   own window (or in your browser, if WebKitGTK isn't installed). Node.js is
   included - nothing else to install.

4. The tray icon's menu opens Serene Pub again (in a window or your browser),
   chooses which one is the default, shows the logs, and has "Quit", which is
   how you stop Serene Pub. Closing the window does not stop it.

   No tray icon? Plain GNOME shows tray icons only with the AppIndicator
   extension. Serene Pub runs fine without it.

5. Optional: run "install-desktop-shortcut.sh" once to add Serene Pub to your
   desktop's application menu. Run it again if you move this folder.

Headless, systemd, ssh, or debugging a startup problem? Run "app/run.sh"
instead. It starts the server and nothing else - no tray, nothing opens - and
prints its output to the terminal. Stop it with Ctrl+C.

Configuration
-------------

Serene Pub runs with no configuration at all - this section is only for
changing something specific, like the port.

Settings go in a ".env" file in your DATA directory, not in this folder:

      ~/.local/share/SerenePub/.env

".env.example" (at the top of this folder) lists every available setting with
an explanation; copy it to the path above and edit it there. Common ones:

   - PORT=3000                    change the web UI's port
   - HOST=127.0.0.1               local connections only
   - AUTO_OPEN_CLIENT=0           don't open Serene Pub on startup
   - SERENE_PUB_DATA_DIR=...      keep your data somewhere else entirely

(SERENE_PUB_DATA_DIR is the one exception: it chooses the data directory, so it
has to be set in a ".env" at the top of this folder, or as a real environment
variable. A relative path like "./data" is resolved against this folder.)

Updating
--------

An administrator can update from inside Serene Pub: Admin > Updates. If the
new version fails to start, the old one is put back automatically.

By hand: quit Serene Pub, then extract the new release over this folder,
replacing files when asked. Your database and settings are untouched - they
live in your data directory, not here.

Troubleshooting
---------------

- Nothing opened: click the tray icon, or open http://localhost:3000.
- It stopped: choose "View Logs" from the tray icon. "server.log" is what the
  app printed; include its last lines when asking for help.
- Nothing happens at all: run "./serene-pub" or "app/run.sh" from a terminal
  to see why.
- Using it from your phone: run "hostname -I", then open
  http://<that address>:3000 on the phone (same Wi-Fi).

Uninstall
---------

- Quit Serene Pub, then delete this folder.
- Your characters, sessions, settings and logs live separately, in
  ~/.local/share/SerenePub - delete that too if you want everything gone.
- If you ran install-desktop-shortcut.sh, also remove
  ~/.local/share/applications/serene-pub.desktop

Enjoy using Serene Pub!
