Welcome to Serene Pub for macOS!

Thank you for downloading Serene Pub.

What's in this folder
---------------------

   serene-pub/
     Serene Pub.app               <- double-click to start
     run.sh                       <- starts only the server, from a terminal
     .env.example                 <- settings reference

Everything that IS the application lives inside "Serene Pub.app". An update
replaces the app in a single move, which is why nothing you own is kept inside
it - your database and settings live in your data directory instead (see
Configuration below). You can drag "Serene Pub.app" into Applications.

To run the app
--------------

1. Double-click "Serene Pub.app".

2. The first time, macOS refuses it, because Serene Pub isn't registered with
   Apple. Click "Done". Then open System Settings > Privacy & Security, scroll
   down to the message about Serene Pub, and click "Open Anyway".

   Or, in Terminal, once (use the path to wherever the app is):

         xattr -dr com.apple.quarantine "/Applications/Serene Pub.app"

   You only do this once: updates installed from inside Serene Pub are not
   blocked again.

3. A Serene Pub icon appears in the menu bar (top right), and Serene Pub opens
   in its own window. Node.js is included - nothing else to install.

4. The menu-bar icon's menu opens Serene Pub again (in a window or your
   browser), chooses which one is the default, shows the logs, and has "Quit",
   which is how you stop Serene Pub. Closing the window does not stop it.

Headless Mac, a launchd job, or debugging a startup problem? Run "run.sh" in
this folder from Terminal (or "Serene Pub.app/Contents/Resources/app/run.sh"
from wherever the app is). It starts the server and nothing else - no menu-bar
icon, nothing opens - and prints its output. Stop it with Ctrl+C.

Configuration
-------------

Serene Pub runs with no configuration at all - this section is only for
changing something specific, like the port.

Settings go in a ".env" file in your DATA directory, not in the app:

      ~/Library/Application Support/SerenePub/.env

".env.example" (in this folder) lists every available setting with an
explanation; copy it to the path above and edit it there. Common ones:

   - PORT=3000                    change the web UI's port
   - HOST=127.0.0.1               local connections only
   - AUTO_OPEN_CLIENT=0           don't open Serene Pub on startup
   - SERENE_PUB_DATA_DIR=...      keep your data somewhere else entirely

Never edit files inside "Serene Pub.app": that breaks its signature and macOS
will refuse to open it.

(SERENE_PUB_DATA_DIR is the one exception: it chooses the data directory, so it
has to be set in a ".env" in the folder that contains "Serene Pub.app", or as a
real environment variable. A relative path is resolved against that folder.)

Updating
--------

An administrator can update from inside Serene Pub: Admin > Updates. If the
new version fails to start, the old one is put back automatically.

By hand: quit Serene Pub, then replace "Serene Pub.app" with the new one. Your
database and settings are untouched - they live in your data directory.

Troubleshooting
---------------

- Nothing opened: click the menu-bar icon, or open http://localhost:3000.
- It stopped: choose "View Logs" from the menu-bar icon. "server.log" is what
  the app printed; include its last lines when asking for help.
- "Serene Pub is damaged and can't be opened": run the xattr command above.
- Nothing happens at all: run "bash run.sh" in this folder from Terminal to
  see why.
- Using it from your phone: run "ipconfig getifaddr en0", then open
  http://<that address>:3000 on the phone (same Wi-Fi).

Uninstall
---------

- Quit Serene Pub, then delete "Serene Pub.app" (and this folder).
- Your characters, sessions, settings and logs live separately, in
  ~/Library/Application Support/SerenePub - delete that too if you want
  everything gone.

Enjoy using Serene Pub!
